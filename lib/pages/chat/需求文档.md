# 聊天页 · 需求文档

> 模块位置：`lib/pages/chat/`
> 路径：悬浮导航球3号位 → 聊天页

---

## 整体布局

### 背景
- 用户自定义背景图
- 覆盖半透明遮罩，保证文字可读
- 背景可随时更换

### 顶部栏
- 左侧：男主头像（圆形，点击 → 男主的小世界）
  - 小世界内容：男主视角记录的日记/约定/故事，藏在头像后面的彩蛋
- 中间：用户给男主取的名字（默认"沈星回"，男主系统设置里可改）
- 显示当前对话的形象名（如"与 校园版 聊天中"）
- 右侧：更多按钮（待定）

### 消息区域
- 男主消息：左侧头像 + 气泡
- 用户消息：右侧头像 + 气泡
- 打字闪烁动画（正在输入…）

### 底部输入区
- 左侧：📷 拍照
- 中间：圆角输入框（占位："输入文字…"）
- 右侧：🎤 语音输入
- 最右：圆形 [+] 按钮 → 弹出功能菜单

### [+] 弹出菜单
- 📷 相册（上传图片）
- 😊 表情包（预设表情面板）
- 🧧 红包
- 📞 打电话
- （未来扩展）

## 交互：左右滑

### 交互方式
- 聊天主页面被推开（像DeepSeek官方APP）
- 推开后主页面变成圆角卡片
- 露出的侧边栏填充阴影背景
- 左右滑动效果相同，方向对称

### 左滑 → 选择男主/形象

**布局规则：**
- 每个男主一个横向框
- 框左侧：男主的半身立绘（大尺寸纵向）
- 框右侧上半：男主姓名 + 一句语录
- 框右侧下半：当前对话的形象名
- 默认收起：只显示立绘+姓名+语录+当前身份
- 点击立绘区域 → 展开/收起该男主下的形象列表

**展开后：**
- 每个形象一行：圆形头像 + 名字
- 当前对话形象用发光边框/高亮线框突出
- 形象列表底部：一个加号框（同尺寸，无头像无姓名，只有加号和"新建身份"）

**底部左下角：** [+] 新建男主按钮（DeepSeek用户头像位置）

### 右滑 → 当前角色设置

从上到下排列：

1. **API 密钥**
2. **设备开关列表**（小玩具、智能家居、机器人……未来扩展）
3. **Prompt 编辑区**
   - 上半：**自由书写区** — 用户写自然语言，管家待整理
   - 中间：**[🔍 整理]** 按钮 — 点击后AI分析
   - 下半：**管家整理结果** — 结构化展示（见下方详细说明）
4. **未处理原文区** — 用户未确认的原文保留位置
5. **屏蔽词设置**

## Prompt 系统

### 用户操作流程

1. 在右滑栏的**自由书写区**写自然语言
   - 随便写，不需要格式，不需要分类
   - 想到哪写到哪
2. 点击 **[🔍 整理]** 按钮
3. AI 分析内容 → 提取关键词 + 分类 + 优化句子
4. 结果展示在**管家整理结果**区（树形结构）
   - 每条有：分类 → 关键词 → 具体内容（人话解释）
5. 用户操作：
   - ✅ **确认全部** → 所有内容入库
   - ✅ **逐条确认** → 只确认同意的
   - ✏️ **修改** → 手动改写内容
   - ❌ **退回** → 该条回到未处理区
6. 确认的内容 → 自动进入 Prompt 数据区
7. 自由书写区清空
8. 未确认的原文 → 保留在**未处理原文区**

### 管家整理结果展示（树形结构）

```
家人
  └─ 妈妈
      关联：经历·弑母
      内容：原本是温柔的母亲，会在夜里给年幼的他讲故事
           12岁时发现她被怪物寄生，被迫亲手杀了她

经历
  └─ 弑母
      内容：12岁被迫杀死被寄生的母亲，成为一生的阴影

性格
  └─ 怕孤独但不表现出来
      内容：长期流浪养成的习惯，外表温柔疏离

宠物
  └─ 月牙（黑猫）
      内容：逃亡时带出来的唯一伙伴
```

- 每条内容后面跟着**完整的人话描述**（不是关键词堆砌）
- AI 根据这些具体描述来生成回复

### 管家数据存储结构

```
每条记忆 = 关键词 + 关联关键词 + 具体内容

示例：
关键词：弑母
关联：妈妈、经历、悲伤、童年
内容：12岁那年发现妈妈被怪物寄生，被迫杀了她

关键词：妈妈
关联：温柔、被寄生、弑母
内容：原本很温柔，会在夜里讲故事，后被怪物寄生
```

- 管家不存详细内容，只存**关联关系**（关联表）
- 具体内容在 Prompt 里，AI 自己读
- 管家标记"这几条是连在一起的"

### 系统预设分类（兜底用）

```
家人 | 经历 | 性格 | 情绪 | 日常 | 人际关系 | 喜好
```

- 约5-8个通用分类
- 管家自动把用户内容归入对应分类
- 用户可手动调整
- 用户自定义关键词是血肉，系统分类是骨架

### 额外注入 Prompt（场景化）

**位置：** 右滑栏 → Prompt 区内

用户可创建多个场景包，每个场景包含：
- 场景名（如"色色模式"、"战斗模式"）
- 触发关键词组合（如"星星+色色"）
- 具体 Prompt 内容（用户写行为、风格、喜好等）
- 触发方式：关键词自动 / 手动切换
- 启用开关

管家在检测到关键词组合时，自动注入对应场景的 Prompt。

### 形象记忆共享

**位置：** 右滑栏 → Prompt 区内 → 形象关系

分为两种场景：

**场景1：同一男主的不同形象**
- 每个形象可独立设置继承记忆来源
- 如 A3（重生版）→ 继承自 A1（校园版）
- 可细粒度选择继承范围：经历√ 性格×
- 默认：所有形象不互相继承

**场景2：不同男主之间建群**
- 用户可创建"群"，将多个男主/形象放入同一对话语境
- 群内角色共享聊天语境

### 群聊机制

**入口：** 左滑栏 → 男主立绘列表下方
- 群没有半身立绘，使用群封面图（可放照片）
- 其他和男主立绘框布局相同

**核心规则：**

1. **同步开关**
   - 全同步：所有群成员都收到消息（都消耗 token）
   - 管家判断：只有可能回复的成员才收到消息（省 token）
   - @唤醒：用户提到某男主名字 → 强制推送，不受管家判断影响

2. **发言机制**
   - 每个男主基于自己的 Prompt/性格独立判断是否回复
   - 每次不一定所有人都回
   - 用户 @某个男主 → 该男主必须回应
   - 其他男主可追问/插话

3. **上下文传递（管家职责）**
   - 管家只做三件事：
     ① 截取最近 N 条对话原文
     ② 传给被唤醒/被同步的男主
     ③ 记录已读/未回状态
   - 管家不做"理解"和"生成"工作
   - 新成员入群：管家把最近对话原文截取一段作为上下文传过去

4. **群聊设置**
   - 成员管理（拉入/踢出）
   - 同步模式：全同步 / 管家判断
   - 发言机制：@唤醒 / 管家判断
- 可用于多角色同场对话场景

### 推送逻辑

1. 用户提到某个词 → 管家查关联表 → 找到关联的关键词
2. 把关联到的内容（含具体描述）推给 AI
3. AI 根据具体内容生成回复
4. **关键词 + 具体内容缺一不可**
   - 没关键词：管家不知道怎么找
   - 没具体内容：AI 不知道怎么回

## 男主个人主页（点头像进入）

### 入口
聊天页 → 点击顶部男主头像 → 男主的小世界

### 内容
- 男主视角记录的故事/约定/日常
- 藏在头像后面的小彩蛋
- 不是功能设置页面，是情感向内容

## 视觉风格要求

### 整体
- 主色调：粉色系（具体色值待定）
- 所有容器/卡片：毛玻璃效果（frosted glass）
- 圆角统一且柔和
- 信息间距留白充足
- 不厚不糊的毛玻璃（不是厚厚一层白）

### 侧边栏（左右滑）
- 参考恋与深空/DeepSeek风格
- 大圆角 + 半透毛玻璃
- 聊天主页面被推成圆角卡片
- 露出空间填充阴影背景
- 干净简洁，无复杂边框

### 当前高亮
- 当前对话的形象用**发光边框**突出
- 一眼就能看到正在跟谁聊
